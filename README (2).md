# وثيقة ملكية رسمية — رسالة إلى جلالة الملك سلمان

صفحة ويب رسمية للرسالة الملكية (عربي / إنجليزي / فرنسي / فلامس).

## النشر على GitHub Pages (خطوة بخطوة)

### 1. إنشاء مستودع جديد
1. اذهب إلى [github.com/new](https://github.com/new)
2. سمِّ المستودع مثلاً: `royal-letter` (أو أي اسم تريده)
3. اختر **Public**
4. **لا** تضف README أو .gitignore (سنرفع الملفات يدوياً)
5. اضغط **Create repository**

### 2. رفع الملفات
ارفع الملفين التاليين فقط إلى جذر المستودع (Root):

| الملف          | الوصف                          |
|----------------|--------------------------------|
| `index.html`   | الصفحة الرئيسية (ضروري)        |
| `README.md`    | هذا الملف (اختياري)            |

**طريقة الرفع الأسهل:**
- اضغط **Add file → Upload files**
- اسحب `index.html` و `README.md`
- اكتب رسالة commit مثل: `Add royal letter page`
- اضغط **Commit changes**

### 3. تفعيل GitHub Pages
1. اذهب إلى **Settings** في المستودع
2. من القائمة الجانبية اختر **Pages**
3. تحت **Source** اختر:
   - Branch: `main` (أو `master`)
   - Folder: `/ (root)`
4. اضغط **Save**

### 4. الانتظار والحصول على الرابط
- انتظر دقيقة أو دقيقتين
- سيظهر الرابط بالشكل:
  ```
  https://USERNAME.github.io/REPO-NAME/
  ```
  مثال: `https://rida-hamada.github.io/royal-letter/`

## ملاحظات مهمة

- الصفحة تعمل **بدون** أي بناء (build) أو Node.js.
- الخطوط (Amiri + Cinzel) تُحمَّل من Google Fonts (تحتاج إنترنت).
- اللغة الافتراضية هي العربية (RTL).
- يمكنك تغيير اللغة من الأزرار في أعلى الصفحة.
- الملف جاهز للطباعة والعرض على الموبايل والحاسوب.

## هيكل الملفات المطلوب

```
your-repo/
├── index.html      ← الصفحة الرئيسية
└── README.md       ← هذا الملف (اختياري)
```

لا تحتاج إلى `package.json` أو `node_modules` أو أي ملفات أخرى.
